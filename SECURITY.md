# Security policy

EzTorrent is an unreleased project. Foundation source and planning are public on GitHub; no packages, installer or release have been published.

## Report a vulnerability privately

Use [GitHub private vulnerability reporting](https://github.com/rromeradev/EzTorrent/security/advisories/new) for security-sensitive reports. Private reporting is enabled for this repository. Do not post exploitable details, private tracker URLs/passkeys, real magnet links, torrent hashes, local paths or personal data in public issues.

Include a minimal sanitized reproduction, affected version/commit when available, impact and relevant environment. No response-time guarantee or support contact is invented here.

## Supported versions

No stable or beta release exists yet. A supported-release policy will be finalized before v1.0.0. Windows compatibility, protocol support and authenticated updates must be verified before being advertised. The planned privacy/path/private-torrent/update-trust boundaries are recorded in the requirements and project guide.
